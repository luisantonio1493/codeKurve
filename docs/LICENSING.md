# Licensing

**Status: pending.** No open-source license has been chosen. Ownership and
distribution terms are unresolved (plan §40).

Before any public license is chosen, the plan requires:

1. Clarifying intellectual property ownership.
2. Reviewing employer policy.
3. Deciding whether the project is internal, personal, or open source.
4. Reviewing dependency licenses.
5. Generating notices.

Until resolved:

- No default open-source license is applied — "no license" legally means
  all rights reserved, not "do whatever you want."
- No code from Graphify, CodeGraph, or any other proprietary tool is
  copied — general ideas and patterns only, with inspiration documented
  without assuming license compatibility.

**2026-08-02 update**: the repository was made public and `v0.1.0` release
binaries are published on GitHub Releases (installable via `install.sh`/
`install.ps1`, see `README.md`), to unblock real installation for Phase 8's
pilot. This was a deliberate, scoped choice — it does **not** resolve any of
the five items above, and does not itself grant a license to redistribute or
modify the source. Treat "public and installable" and "licensed" as two
separate, still-open questions.

This document intentionally does not name a license. See `README.md` and
`CONTRIBUTING.md` for the licensing notice shown elsewhere.
